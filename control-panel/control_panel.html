Trigger Actions

Use * as a wildcard in the trigger. Example: Twitch * sub. You can use multiple triggers separated by commas.
Variables: Use parameters like {username}, {message} (or {1}, {2} for wildcard matches). Math logic like {1}*2(2/{2})+7 and Global variables {global.name} are also supported.

🌐 Global Variables

Persistent global variables (e.g. death counter, points, sub goals, minigame states). Access anywhere via {global.variable_name} or {variable_name} in trigger text, overlay messages, and math formulas (e.g. {{ {global.death_count} + 1 }}).
